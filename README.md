# Tailwind CSS Practice

A collection of small HTML files built while learning and practicing core Tailwind CSS utility concepts for quick lookup.

## Pages Included
* `index.html` – Main navigation hub
* `color.html` – Colors and backgrounds
* `flex.html` – Flexbox layouts
* `grid.html` – CSS Grid layouts
* `practice.html` – General practice exercises
* `responsiveness.html` – Responsive breakpoints
* `spacing.html` – Padding and margin utilities
* `state.html` – Hover, focus, and state variants
* `typography.html` – Font sizes, weights, and text styling
